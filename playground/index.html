🐔 chicken-player

Un player vidéo qui ne pond pas de problèmes. · Documentation · GitHub

Contrôles
Initialisation 
import ChickenPlayer from 'chicken-player'

new ChickenPlayer({
  selector: '.chicken-player',
  cookies: { active: true, types: ['youtube', 'vimeo', 'dailymotion'] },
  player: {
    dailymotion: { playerId: 'xa19h' },
  },
})
